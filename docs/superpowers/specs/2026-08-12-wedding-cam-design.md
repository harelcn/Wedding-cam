# Wedding Cam — מסמך עיצוב

## סקירה כללית

אתר כללי (לא רק לחתונות) שמאפשר לכל אחד ליצור "תיקייה" משותפת לאירוע. משתתפי האירוע מצטרפים דרך סריקת QR, מצלמים/מעלים תמונות וסרטונים דרך הדפדפן בטלפון שלהם, וכל מה שמצולם מסתנכרן בזמן אמת לתיקייה המשותפת אצל כל המשתתפים. אין התחברות (זיהוי לפי מכשיר), ואין אפשרות מחיקה בשום מקום במערכת.

## Stack טכנולוגי

- **Frontend:** React + Vite + TypeScript, React Router. עיצוב: זית-לבן (ירוק זית כרקע, טקסט לבן), מקצועי ונקי.
- **Database + Realtime:** Supabase (Postgres + Realtime subscriptions)
- **אחסון קבצים:** Cloudflare R2 (S3-compatible, ללא עלות egress) — bucket ציבורי לקריאה, כתיבה רק דרך presigned URL
- **API שכבה דקה:** Vercel Serverless Functions (בתיקיית `/api`) — אחראית אך ורק על הנפקת presigned upload URLs ל-R2 (המפתחות של R2 לא נחשפים בדפדפן)
- **Hosting:** Vercel, מחובר ל-GitHub repo (`harelcn/Wedding-cam`). המשתמש מחבר את הפרויקט ל-Vercel בעצמו.
- **זיהוי משתמש:** ID אנונימי שנוצר בכניסה הראשונה ונשמר ב-localStorage. אין הרשמה/התחברות.

## מבנה נתונים (Supabase / Postgres)

### טבלת `folders`
| שדה | טיפוס | הערות |
|---|---|---|
| id | uuid (PK) | נוצר אקראית, לא ניחוש — משמש גם כ-join code בקישור ה-QR |
| name | text | שם התיקייה כפי שהוזן ביצירה |
| created_at | timestamptz | |
| creator_device_id | text | מזהה המכשיר היוצר (למטרות תיעוד בלבד, לא לאכיפת הרשאות) |

### טבלת `media`
| שדה | טיפוס | הערות |
|---|---|---|
| id | uuid (PK) | |
| folder_id | uuid (FK → folders.id) | |
| storage_key | text | הנתיב באובייקט ב-R2 (`{folder_id}/{media_id}.{ext}`) |
| type | text | `image` \| `video` |
| uploader_device_id | text | |
| uploaded_at | timestamptz | |
| file_size_bytes | integer | |

**אין טבלת "folder_members"** — רשימת "התיקיות שלי" נשמרת אך ורק ב-localStorage בכל מכשיר (תיקיות שנוצרו + תיקיות שהוצטרפו). מחליף מכשיר = מתחיל רשימה מחדש. זו החלטה מכוונת לפשטות (אין login).

### RLS (Row Level Security) ב-Supabase
- `folders`: insert/select פתוחים לכולם (anon key). **אין policy למחיקה או עדכון** — כל ניסיון מחיקה נכשל ברמת ה-DB.
- `media`: insert/select פתוחים לכולם. **אין policy למחיקה** — הגנה כפולה מעבר לכך שאין כפתור מחיקה ב-UI.

## זרימות עיקריות

### יצירת תיקייה
1. משתמש לוחץ "צור תיקייה" → מזין שם
2. `INSERT` ל-`folders` (Supabase client, מהדפדפן ישירות)
3. נשמר ל-localStorage תחת "התיקיות שלי" (role: creator)
4. מוצג מסך עם קוד QR שמקודד `https://<domain>/join/{folder_id}`
5. כפתור "שתף בוואטסאפ" — משתמש ב-Web Share API (`navigator.share` עם קובץ תמונה של ה-QR) לפתיחת תפריט שיתוף נייטיבי; fallback לכפתור "הורד תמונה" בדפדפנים ללא תמיכה (בעיקר דסקטופ)

### הצטרפות לתיקייה (סריקה)
1. משתמש לוחץ "סרוק קוד" → נפתחת מצלמה עם סורק QR מובנה (או: סריקה ישירה עם מצלמת הטלפון הרגילה שפותחת את הקישור)
2. מגיע ל-`/join/{folder_id}` → מסך אישור עם שם התיקייה + כפתור "הצטרף"
3. באישור: `SELECT` לוודא שהתיקייה קיימת → נשמר ל-localStorage תחת "התיקיות שלי" (role: joined) → מנווט לתוך התיקייה
4. אם ה-folder_id לא קיים: הודעת שגיאה ברורה ("הקישור לא תקין")

### צילום/העלאה בתוך תיקייה
1. **צילום תמונה:** ממשק מצלמה בתוך האפליקציה (`getUserMedia` + צילום ל-canvas). דחיסה בדפדפן (resize ל-~1920px בצלע הארוכה, JPEG) לפני העלאה.
2. **צילום וידאו:** הקלטה בתוך האפליקציה (`MediaRecorder`), מוגבל ל-60 שניות (עצירה אוטומטית).
3. **העלאת קובץ מהגלריה:** `<input type="file" accept="image/*,video/*">`, אותה דחיסה/הגבלה חלה גם על קבצים שמועלים (וידאו ארוך מ-60 שניות נדחה עם הודעה).
4. בקשה ל-`/api/upload-url` (Vercel function) עם `folder_id` + סוג קובץ → מחזיר presigned PUT URL + `storage_key`
5. `PUT` ישיר מהדפדפן ל-R2 עם ה-URL הזמני
6. `INSERT` ל-`media` table עם פרטי הקובץ
7. Supabase Realtime משדר את השינוי → כל המכשירים המחוברים לאותה תיקייה מרעננים את הגלריה אוטומטית

### צפייה/הורדה
1. מסך תיקייה מציג גלריית רשת (grid) של כל המדיה, ממוינת מהחדש לישן, עם listener ל-Realtime לעדכונים חיים
2. מצב "בחירה": checkbox על כל פריט + כפתור "בחר הכל"
3. "הורד" על הבחירה: לכל קובץ נבחר מתבצעת הורדה נפרדת ישירות לגלריית הטלפון (בדומה להורדת כמה תמונות מוואטסאפ) — **לא** נארז ל-ZIP
4. **אין בשום מקום כפתור/אפשרות מחיקה**

## מסכי האפליקציה (routes)

| Route | תיאור |
|---|---|
| `/` | מסך בית — 3 כפתורים: צור תיקייה / סרוק קוד / התיקיות שלי |
| `/create` | יצירת תיקייה חדשה |
| `/join/:folderId` | מסך אישור הצטרפות |
| `/my-folders` | רשימת תיקיות (נוצרו + הצטרפו), מ-localStorage |
| `/folder/:folderId` | גלריה + מצלמה + העלאה + בחירה/הורדה |

## עיצוב ויזואלי

- צבע רקע עיקרי: ירוק זית `#6B6E3A`, גוון כהה יותר להדגשות/כותרות `#4E5129`
- טקסט: לבן `#FFFFFF`
- סגנון: מקצועי, נקי, מהיר לטעינה — מותאם מובייל-first (רוב השימוש יהיה מהטלפון)

## טיפול בשגיאות ומקרי קצה

- **קישור QR לא תקין / תיקייה לא קיימת:** הודעת שגיאה + קישור חזרה לדף הבית
- **וידאו ארוך מ-60 שניות (מהעלאה, לא צילום פנימי):** נדחה עם הודעה לפני העלאה
- **כשל בהעלאה (רשת חלשה וכו'):** הצגת שגיאה + אפשרות ניסיון חוזר, ללא איבוד הקובץ שנבחר
- **דפדפן ללא תמיכה ב-`navigator.share`:** נופל חזרה לכפתור הורדת תמונת QR
- **דפדפן ללא תמיכה במצלמה מובנית (getUserMedia חסום/לא נתמך):** נופל חזרה ל-`<input capture>` שפותח את אפליקציית המצלמה הנייטיבית של הטלפון
- **מכסת האחסון החינמית (R2 10GB / Supabase) מתקרבת לסיום:** מחוץ לתחום גרסה ראשונה — יטופל בעתיד אם יידרש (לא חוסם עכשיו)
